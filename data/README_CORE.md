# Ядро ассистента

## Что внутри
- Чат с внешней LLM (LM Studio / OpenAI-compatible)
- Минимальное окно
- Настройки: Основные + Плагины (с диска)
- Пустая папка `plugins/` — сюда добавляются плагины

## Запуск
```bat
cd data
python main.py
```

## Добавить плагин
1. Создать `plugins/my_plugin/plugin.py` с классом `PluginImpl`
2. Перезапустить
3. Вкладка «Плагины» — новый пункт

## Удалить плагин
Удалить папку `plugins/my_plugin` → после перезапуска пункта нет.
