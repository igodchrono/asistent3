Фикс долговременной памяти для asistent3
=======================================

Записи есть во вкладке «Память», после перезапуска персонаж «забыл».

Причина: в prompt попадали только факты, у которых текст ЦЕЛИКОМ
совпадал с текущей репликой («привет»). Закреплённые факты не
подмешивались.

Куда копировать (поверх):
  D:\asistent\data\plugins\memory\store.py
  D:\asistent\data\plugins\memory\plugin.py

Перезапустить ассистента.

Проверка:
  1) «запомни что меня зовут Иван»
  2) закрыть программу
  3) открыть снова
  4) «привет» / «как меня зовут»
     — в ответе должен быть Иван.

В консоли при старте должно быть:
  🧠 memory: <персонаж> → ...\memory\memory.db (n=N)
N > 0 — база открылась та же.

Плагин plugins/memory_persona для asistent3 не нужен
(он патчит старый PersistentMemory, которого в ядре уже нет).
