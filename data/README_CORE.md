# Ядро ассистента

См. README.md в корне репозитория.

## Запуск
`start.bat` из корня (Windows). Или:
```bat
cd data
python main.py
```

Плагины — папки в `plugins/`. Настройки — `settings.json` (из `settings.example.json`).
Память персонажа — одно хранилище: `personas/characters/<id>/memory/memory.db`.
